Hashnode Platform

A full-stack blogging platform developed using React.js, Node.js, Express.js, and MongoDB.

Features

- User registration and login
- Secure authentication using JWT and bcrypt
- Create, edit, and delete blog posts
- Save posts as drafts or publish them
- Markdown support for blog content
- Add tags to posts
- Upload cover images
- Dashboard to manage posts
- Public post details page

Technologies Used

- React.js
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- React Markdown

Project Structure

- "client" — Frontend application
- "server" — Backend API and database integration

How to Run the Project

Backend

1. Open a terminal in the "server" folder.
2. Run "npm install".
3. Configure the required environment variables in ".env".
4. Run "node server.js".

Frontend

1. Open another terminal in the "client" folder.
2. Run "npm install".
3. Run "npm run dev".
4. Open the local URL displayed in the terminal.

Project Objective

The objective of this project is to build a blogging platform where users can authenticate themselves and create, manage, and publish blog posts.
